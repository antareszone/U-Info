# Статистический ежегодник Украины за 1993 год: части PDF

**«Народне господарство України у 1993 році: статистичний щорічник».**
Міністерство статистики України. Київ: Техніка, 1994.

Это два последовательных фрагмента **одного PDF**, а не два документа и не
архивы для самостоятельной распаковки. Полный файл: **119 701 125 байт,
494 PDF-страницы**. Страницы PDF не следует автоматически приравнивать к
печатным номерам страниц.

## Происхождение и права

Каталог источника: https://istmat.org/node/68214 . Эта ссылка и выходные данные
взяты из `Economy/data/sources_extra.csv`, источник `1009` в Ukr. Название
папки указывает на копию с `cdn.ruarxive.org/public/saved/istmat/books/68214/1`;
точный URL загрузки и содержимое удалённой копии в рамках этой проверки
независимо не подтверждались. Это не заявление об успешном повторном скачивании.

**Явная лицензия на повторную публикацию скана не установлена.** Статус
исторической официальной статистики сам по себе не подтверждает права на
распространение скана. Перед публикацией частей в открытом U-Info следует
проверить условия распространения. Эти метаданные не снимают это ограничение.

## Проверка и сборка

`manifest.json` содержит размер и SHA-256 каждой части и целого PDF.
Порядок строго такой:

1. `part1.bin` — 59 850 563 байта;
2. `part2.bin` — 59 850 562 байта.

Нужно соединить **байты без разделителя**, не менять кодировку и не открывать
части в текстовом редакторе. Проверяемая сборка стандартным Python:

```sh
python assemble.py PATH_TO_NEW_OUTPUT.pdf
```

Скрипт проверяет каждую часть и общий SHA-256; существующий результат не
перезаписывается. На выходе потребуется дополнительно около 114,2 МиБ.
Частичный результат при ошибке удаляется.

Полный PDF был локально собран и разобран pypdf: найдено 494 страницы.
Это проверка структуры, **не** подтверждение правильности OCR, всех чисел
или полноты импорта таблиц. Исходный контрольный хеш издателя не сверялся.

## Как разместить в U-Info

Если право распространения подтверждено, переносить **весь этот комплект**:
оба `.bin`, этот README, `manifest.json`, `assemble.py`. Не менять имена
частей и контрольные суммы. Сначала проверить загруженные копии и сборку,
только после этого рассматривать удаление бинарных частей из Ukr.

В Ukr оставить копии README и manifest, а также журнал
`TempFiles/ocr_audit/visual_audit_progress.md`. Журнал перечисляет проверенные
по сканам страницы и ограничения OCR; он не является временным мусором.

В рамках подготовки комплекта бинарные части **не удалялись** и в новый
репозиторий автоматически не публиковались.
